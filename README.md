# OOP Lab 01: Introduction to Classes and Objects (Java)

Welcome to Lab 01. After our Git workshop, this session marks our transition from procedural programming to Object-Oriented Programming (OOP) in Java using the Eclipse IDE.

## Objective
Understand and apply core OOP concepts by modeling real-world entities. You will learn how to build blueprints (`Classes`) and instantiate tangible entities (`Objects`) with specific states (`Attributes`) and behaviors (`Methods`).

## Contents
- `Student.java`: The class template.
- `MainApp.java`: The main execution program.
- **Individual Tasks:** 4 hands-on exercises to mutate state and add new behaviors.
